# Zipo Nkefe — React Portfolio

A professional, dark-themed recruiter portfolio built with React + Vite.

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite address shown in the terminal.

## Build for hosting

```bash
npm run build
```

The production files are generated in `dist/`.

## Add your photo

Put your photo in:

`public/profile.jpg`

The website already contains the photo section. If `profile.jpg` is missing, it displays a professional placeholder instead.

## Deployment

This is a static Vite/React site and can be hosted on Vercel, Netlify or GitHub Pages.

For Vercel:
1. Push the project to GitHub.
2. Import the repository into Vercel.
3. Build command: `npm run build`
4. Output directory: `dist`
